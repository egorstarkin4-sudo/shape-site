Регистрируясь на сайте, приобретая подписку или скачивая клиент Shape, вы подтверждаете, что полностью прочитали, поняли и принимаете условия настоящего Соглашения.

2. Описание сервиса

Shape Visuals — это модификация (мод) для игры Minecraft версии 1.21.4 на платформе Fabric Loader, предоставляющая визуальные улучшения геймплея: кастомные ViewModel, шейдерные эффекты Chams, ESP-подсветку, адаптивный HUD, косметические элементы и другие функции.

Сервис включает:

  • Веб-сайт для регистрации, авторизации и управления лицензией;
  • Систему лицензионных ключей для активации подписки;
  • Скачивание клиентского файла (shape.jar);
  • Систему привязки аппаратного идентификатора (HWID).

5. Привязка HWID

5.1. При первом запуске клиента Shape в игре Minecraft, модификация автоматически привязывает аппаратный идентификатор вашего компьютера (HWID) к вашему профилю.

5.2. Одна подписка может быть активна только на одном устройстве одновременно.

5.3. Для переноса лицензии на другое устройство необходимо выполнить сброс HWID (бесплатно для администратора, платно через ключ «Сброс HWID» для обычных пользователей).
